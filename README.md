# The-Keeper
A 2D platformer I developed in Unity where the player navigates through levels, collects shotgun shells, and uses the shotgun to propell their charachter trough hazards. A teaser of the game can be seen on: https://www.youtube.com/watch?v=C5jkyNQx8X0.

> Note: Created in 2023 and later uploaded to GitHub. No Git history is available as development was done locally without version control.
